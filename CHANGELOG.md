# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-07-15

Initial public release.

- 16 model-agnostic, language-agnostic AI-tells with fixes, ranked by evidence strength.
- Three reference files: before/after code examples, prose/writing tells, and the research corpus with sources and confidence levels.
- Explicit "what is NOT a reliable tell" list (refuted claims) to suppress false positives.
- Verify-by-construction and fix-vs-report discipline in the run procedure.
- Configurable comment-language rule.
- Validator test suite plus GitHub Actions CI.
